### Study Abroad Planner (Team 20)
### Team Members: Daniel Garcia, Tevon Westby, Nicole Lacanlale, and Thalia Ysassi

## Abstract
The Study Abroad Planner web application is designed to help University of Nevada, Reno students find and plan study abroad opportunities in one place. Students will be able to research programs by major and term, save programs they are interested in, estimate expenses with a budget calculator, and explore scholarships. Additional planned features include flight planning, medical requirements, a packing checklist, and scheduling meetings with study abroad advisors. This project uses a React frontend, a Django REST framework backend, and a PostgreSQL database to organize program information and user data.
